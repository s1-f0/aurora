---
title: Work on Aurora itself
description: Clone the repo, run the checkout's own code, and check your change before you send it.
---

The installed `aurora` command runs a release. To change Aurora, clone the repo instead. Inside the clone, `uv run aurora <verb>` runs the checkout's own code:

```bash
git clone https://github.com/balanced7/akashic-aurora.git && cd akashic-aurora
uv sync                      # the locked environment
uv run aurora setup          # hooks, agent id and the repo's git hooks
uv run aurora boot me --task "trying a change"
```

In a clone, the repo's `.mcp.json` already gives Claude Code the `akashic-aurora` tools, and setup also installs the commit checks. [Connect your agent tools](/docs/how-to/connect-your-agent-tools) explains each setup step.

## Check your change

```bash
uv run poe gate    # format, lint, types, guardrails and the fast tests
uv run poe test    # the full test suite
```

[`CONTRIBUTING.md`](https://github.com/balanced7/akashic-aurora/blob/master/CONTRIBUTING.md) explains how to size a change and what a pull request needs.

## Edit these docs

The docs site lives in `apps/docs`. Run it locally, and each page reloads as you save it:

```bash
bun install                           # once, from the repo root
bun run --filter docs dev
bun run --filter docs check:docs     # the checks a docs change must pass
```

## Work on the website

The public website lives in `apps/web`, in the same bun workspace as these docs:

```bash
bun install                                     # once, from the repo root
cp apps/web/.env.example apps/web/.env.local    # local settings
bun run --filter web dev                        # http://localhost:3090
bun run lint && bun run typecheck && bun run test && bun run build
```

[`apps/web/README.md`](https://github.com/balanced7/akashic-aurora/blob/master/apps/web/README.md) covers the production build and how the site is deployed.

## What your agent reads

Agents working in the repo start from [`AGENTS.md`](https://github.com/balanced7/akashic-aurora/blob/master/AGENTS.md). It tells them to boot, learn and recall, and which command to use for what.
